# La isla del Farol de Coral

Un juego de exploración y matemáticas para niñas de 7 a 10 años. Se mueve un
personaje por una isla, se personaliza (pelo, ropa, joyas, complementos,
mascota) y por el camino salen problemas de leer y pensar: lo que se entrena no
es calcular, sino **reconocer qué operación pide un problema**.

**Para jugar:** https://amaslor.github.io/isla-farol-coral/

- Un solo archivo HTML. Sin servidor, sin cuentas, sin librerías externas.
- El progreso se guarda **en el navegador de cada aparato**. No sube nada a
  ningún sitio.
